# APLIKASI KASIR JURAGAN 38

Aplikasi kasir POS berbasis Android dengan fitur lengkap untuk usaha Anda.

## Fitur Utama
- ✅ Multi Login (Admin, Kasir, Manajer)
- ✅ Kasir/POS dengan Keranjang
- ✅ Manajemen Produk & Kategori
- ✅ Stok Otomatis Berkurang
- ✅ Perhitungan Laba/Rugi (HPP vs Harga Jual)
- ✅ Laporan Penjualan Real-time
- ✅ Multi Pembayaran (Tunai, QRIS, Transfer)
- ✅ Cetak Struk Bluetooth
- ✅ Dashboard Statistik
- ✅ Riwayat Transaksi

## Teknologi
- Kotlin + Jetpack Compose
- Room Database (Offline)
- Hilt Dependency Injection
- MVVM Architecture
- Material Design 3

## Download APK

Kamu bisa download APK langsung dari GitHub Actions:

1. Push project ini ke repository GitHub kamu
2. Buka tab **Actions** di repo GitHub
3. Tunggu build selesai (±5-10 menit)
4. Download artifact **JURAGAN-38-APK** yang berisi file `app-debug.apk`

## Cara Setup Lokal

1. Clone repository ini
2. Buka dengan Android Studio (Arctic Fox atau lebih baru)
3. Sync Gradle
4. Run ke emulator atau device

## Default Login
- Username: `admin`
- Password: `admin`

## Build Manual

```bash
./gradlew assembleDebug
```

APK akan tersedia di: `app/build/outputs/apk/debug/app-debug.apk`
